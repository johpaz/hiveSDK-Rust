# Salida estructurada sin bucles de reparación

Se añade `LoopPolicy.structured_output = {name, schema}` y se conserva en `ModelRequest` y checkpoints. La misma validación Rust compila el schema offline al crear el agente y valida JSON final antes de declarar éxito. El contenido sigue siendo texto íntegro; no se añade un objeto numérico parseado que pueda perder precisión al cruzar a JavaScript. Un resultado final malformado o incompatible se conserva con su uso y detiene el turno como `invalid_structured_output`, sin otra solicitud ni reparación por LLM.

Alternativas descartadas: forzar una tool ficticia para emular salida JSON y transformar silenciosamente schemas a subconjuntos de cada proveedor. El schema original se transmite íntegro. Cada proveedor soporta su propio subconjunto y modelos; no se deduce soporte por alias ni se consulta remotamente para decidir. OpenAI Chat usa response_format/json_schema/strict; Anthropic Messages, output_config.format; Gemini GenerateContent, generationConfig.responseMimeType y responseJsonSchema. Interactions y Responses conservan APIs distintas y no se emulan.

Se permite el ciclo de tools existente; solo la respuesta sin llamadas pendientes se valida como salida final. Las tools mantienen validación de argumentos y presupuestos comunes. Compatibilidad de structured outputs + tools depende del proveedor/modelo, se solicita explícitamente por esta configuración y no tiene fallback. Schemas o combinaciones no soportados se rechazan, sin modificar el contrato para intentar otra llamada.

El schema participa en bytes/BPE/framing: el perfil neutral añade structured_output y cada perfil de adaptador incluye su payload real. Gemini no puede eliminar toda generationConfig del conteo al retirar el cap: conserva responseMimeType/responseJsonSchema y elimina solo campos de salida. El uso real sigue siendo el reportado por el proveedor; estas estimaciones no incluyen prompts internos privados del servicio.

Los lectores antiguos rechazan la nueva policy por su contrato estricto; no se ignora al reabrir. Se mantiene ausencia por defecto, sin cambiar solicitudes sin configuración. Pruebas: tres cuerpos nativos JSON/SSE, schemas inválidos antes de efectos, final válido y malformado, tools intermedias, bytes/BPE con schema, uso conocido y parada sin nueva llamada, checkpoint/reapertura y paridad npm/Python. No se usarán modelos de pago para probar el contrato.

Fuentes consultadas: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat), [Anthropic Structured Outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [Gemini GenerateContent](https://ai.google.dev/api/generate-content?hl=en) y [schema público v1beta](https://generativelanguage.googleapis.com/$discovery/rest?version=v1beta).
